QUALITY-BAR.md

What it costs to fake.

E0 is a file that exists, one byte to fake. E1 binds an artifact to a hash the checker recomputes. E2 re-executes the claim. E3 is E2 run by a process that never touched the artifact. Most of what looks finished in this system today does not clear E1 yet.

0/11floors fully E1-or-higher-verified
3/9Foreman skills with a matching hard hook
5stages still required process, not gated
ANDone missing floor fails the whole bar

The live split

Architecture, design-and-scope, and ship-readiness have hard hooks. Conceptualize, the router itself, integration-test, tpm, and validate do not. Do not claim those five are gated. Do not claim they are optional.

What this does not claim

Cost to fake goes up. Victory over deception is not declared. E3 does not hold if the agent can edit the verifier, the git history, or the ledger-writing code. No dedicated red-team pass has been run against these gates.

The full document is in the repo. Read that, not this page, if you are going to argue with the numbers.
