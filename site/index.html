Questions people actually ask

Is this a prompt library?

No. Skills without a hard hook behind them fired 0 out of 3 times when measured. The deny is the mechanism. The skills are the map.

Does it work without Claude Code?

The hooks are Claude Code PreToolUse. Skills can be copied onto Grok or anything else that loads SKILL.md. If you are not on Claude Code, you get the map, not the wall.

Is it finished?

No. The Quality Bar says so with numbers. Three hooks are live. Five Foreman stages still have no gate. Tessera's diff check sits uncalled. Shipping anyway, with the gaps in the repo, is the honest move.
