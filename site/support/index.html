support

What this is, and what it is not.

Where do I file a problem?

GitHub issues on latent-affect/foreman-ft. There is no hosted support desk. This is a solo project.

Which install file do I read?

Humans: README.md. Agents: README.agents.md. Do not copy anyone else's private CLAUDE.md into a clone.

Will hooks fire in Cursor or Grok?

PreToolUse hooks are Claude Code. Skills load anywhere SKILL.md loads. If you only copy skills, you have the map. You do not have the wall.

Why are hyphy, wat, and GifSmith not in this repo?

They are separate products with their own histories. Wrapping an umbrella name around them would be a label with nothing under it. Links are in the footer.

Can I send someone this site as the Show HN link?

No. Show HN is for something they can run. Send the repo. This site is the front door for people who already want the story.
