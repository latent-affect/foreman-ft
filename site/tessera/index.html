One tile. Check it is actually there.

A tessera is one tile set into a floor. The floor only holds if each tile is where it claims to be. Tessera is local and zero-dependency on purpose. A networked system with an API and an auth flow could never sit under a hard gate synchronously the way this can.

The gap, named

The real move was supposed to be this: a ticket marked done gets checked against the actual git diff, not against the closing session's own description. The code for that, discrepancy_for_ticket(), is real. Nobody calls it. Searched every hook and Tessera's own automation. Zero matches. On Tessera's own closed tickets, 83 of 104, eighty percent, closed with no claim event recorded at all. That is the worst rate of any project this system tracks, on the project that built the mechanism meant to catch it.

A schema is a place to write a claim. Tessera has the code to check one against reality and is not running it yet. That is the next thing to build, not a footnote.
