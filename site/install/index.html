Install Foreman.

Clone the repo. Run the install script. Point git hooks at the copy in the tree. Humans stay on the README. Agents follow README.agents.md.

From a clone

git clone https://github.com/latent-affect/foreman-ft.git
cd foreman
sh scripts/install-dev-harness.sh
git config core.hooksPath .githooks

The script fail-closes if a required hook is missing. Runtime paths ship as /path/to/... tokens and get rewritten on install. It never copies a private CLAUDE.md.

New project

Do this before that project's first session. Init fail-closes if the hooks are not already on disk.

python3 skills/foreman/scripts/foreman_init.py /path/to/new/project CODENAME PREFIX ["purpose"]

A Foreman project needs ARCHITECTURE.md at its own root. This repo does not ship one for itself. That is origin, not a template.

Installed means

Hooks

Bollard files under ~/.claude/hooks/. architecture_gate.py has to exist or you are not installed.

Skills

Foreman, code-safety, and research-lifecycle under ~/.claude/skills/. Same tree can be copied to Grok.

Verify

test -f ~/.claude/hooks/architecture_gate.py
test -x .githooks/commit-msg
git config --get core.hooksPath

The last line must print .githooks in the clone.
